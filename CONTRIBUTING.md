# Contributing to EyeCopy

Open an issue with a concise problem description, expected behavior and reproducible steps. Include relevant Windows, device and application versions. Use synthetic media and remove personal information from attachments; see [privacy and local storage](docs/PRIVACY.md).

For code changes, follow the [build instructions](docs/BUILDING.md), keep changes focused, and run checks appropriate to the affected behavior. Describe what changed and how it was verified in the pull request. Device-specific results should identify test conditions without private device identifiers or media.

Keep application profiles, pairing records, downloads, binaries, generated archives and private diagnostics out of commits. Preserve third-party license texts and document dependency changes with the corresponding notices and source information.
