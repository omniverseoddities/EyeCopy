Install and connect

Download Setup-EyeCopy-1.0.0.exe from the repository's Releases page and follow setup. It installs EyeCopy for your Windows account, normally in %LOCALAPPDATA%\Programs\EyeCopy, and creates an uninstall entry. Open EyeCopy from its shortcut.

For portable use, download EyeCopy-Windows-x64.zip, extract its entire EyeCopy folder to a writable local location, and open EyeCopy.exe. Keep the package files together. Both packages target Windows 10/11 on Intel/AMD x64 and include the application runtimes and preview tools.

Apple USB support is required

EyeCopy needs a compatible Apple USB driver and background device transport. If these are missing, install Apple Devices from the Microsoft Store, using Apple's download guidance. Open it once to complete setup. Connect your unlocked device with a data-capable cable and approve Trust on the device when requested.

Existing compatible Apple support can be reused. The Apple Devices window can stay closed afterward; its background USB support must remain available. For a USB 3 link, the device, cable and PC port must all support USB 3. Installing Apple Devices does not guarantee 10 Gbps throughput or any particular file-copy speed.

Choose the device under Your devices. The device panel shows available connection, battery, storage and USB link details. If it is not detected, unlock it, check the cable and port, and see whether Apple Devices recognizes it. Follow Apple's connection checklist for further help.

Browse your files

Photos App displays camera photos and videos. Verified Live Photo pairs appear together with a LIVE badge; downloading one includes its still image and motion video. Search, sort, type filters and grid/list views help navigate the catalogue. Show hidden reveals AAE sidecars and unsupported media entries without removing them from the device.

Files App displays document directories exposed by participating apps through USB File Sharing. Open an app directory and use folder tiles or breadcrumbs to navigate. This service does not expose every location in Files, iCloud Drive, Safari Downloads or private app storage.

When disconnected, the saved catalogue and cached previews remain available. Thumbnails load automatically as they become visible. A file without a saved preview needs the device before a new preview can be obtained.

Download and locate originals

Select files and choose Download selected. With nothing selected, the same button selects all displayed files. Downloads initially use Videos\EyeCopy\device name. Each device has its own folder. The folder icon beside the device opens its downloads in Explorer; the edit icon renames the device and its child folder when Windows permits the name.

On PC identifies a verified original in the device's current default folder. Refresh checks this folder and removes stale marks after local deletion. Default bulk downloads skip these copies and already queued duplicates. Selecting only verified copies displays Already on PC. Copies in other destinations do not receive the mark.

Double-click a preview thumbnail to download its original, or reveal its verified PC copy in Explorer. Drag a tile or its Drag original handle into an Explorer folder for a targeted copy. Local originals use Windows file copying. Device-only originals start transferring after the drop destination is confirmed; Choose folder… is available if Windows cannot report that destination. A temporary destination ticket may appear during the drop.

Downloaded originals retain their original media format. Preview conversion does not alter them.

Upload to Files

Upload to Files opens the Windows file picker. On first use, choose an installed app with USB File Sharing. EyeCopy remembers that provider and creates an EyeCopy folder inside its shared Documents folder. Button uploads go there and show the folder when finished.

In Files App, drag PC files into the displayed directory or onto a folder tile to upload there. Use New folder to create a directory. Upload completion refreshes the listing without switching to the transfer queue.

The visible on-device location depends on the provider. An app may expose it as On My iPhone / On My iPad > app name > EyeCopy. A separate EyeCopy app container requires the optional signed device companion. The desktop application cannot create an iOS app container by itself. Companion source is included for developers and requires separate Apple signing and installation; ordinary shared-app transfers do not need it.

Photos and video playback

Choose a file to see its preview and details. Cached image previews do not mean that the original has been downloaded. Video details show duration when metadata can be read. The player provides play/pause, an original-duration timeline, volume and fullscreen controls.

Stream from device reads media for playback without saving the original to the download folder. Play downloaded original uses a verified PC copy and works while the device is disconnected. If the native format is unsupported, try the compatible preview option. Seeking in a converted preview starts a new segment at the selected time, with a buffering indicator while it loads.

Transfer progress and interruptions

The queue shows destination, bytes, progress, measured MB/s and transfer controls. Sort by newest, oldest, name or status; Hide completed filters history without deleting it. Stop all stops active and pending work, including batches still being prepared. When no active work remains, it becomes Clear all to remove entries without deleting completed originals. Entries awaiting temporary-file cleanup remain visible until cleanup succeeds.

Pause, stop or retry individual transfers from their queue entries. A complete partial download can sometimes be finalized by Retry without fetching its bytes again; retry before clearing the entry if you want to retain that work. Disconnecting leaves the cached catalogue available and shows an offline prompt. Reconnecting restores device access.

Change folder above the queue sets a destination override. Reset restores the applicable device's folder under the shared default location. Transfers already queued retain their destinations.

Delete and restore

ActionEffect
Delete from device in Files AppPermanently deletes the confirmed shared-app files or folders, including approved folder contents. PC copies remain. Recently Deleted and Undo are unavailable for this operation.
Delete from PC in file detailsMoves selected eligible, unchanged tracked downloads from the default device folder to the Windows Recycle Bin after confirmation. Device originals remain.
Trash icon beside a deviceOffers PC cleanup of eligible tracked downloads in its default folder. Device originals, untracked files, changed files and custom destinations remain.

Photos-library deletion is unavailable through this USB route. A selected Live Photo includes both original components when eligible for PC cleanup.

The toolbar and Ctrl+Z / Ctrl+Y undo or redo supported selection, navigation, destination, device-name and PC-cleanup actions. Restoring PC files requires their recorded copies to remain in the Recycle Bin and does not overwrite newer files. Downloads and permanent device deletion cannot be undone. Text fields keep their normal text undo behavior.

Settings and background use

Open Settings at the bottom left to choose a dark color theme, change the shared default folder or toggle Keep running in the background. Preferences save automatically.

Change default folder chooses the parent location for the EyeCopy folder containing all devices. This affects future downloads and stays through restarts; existing files are not moved, copied or deleted. Undo and Redo can restore the preference without migrating files.

With background use enabled, closing the window keeps EyeCopy in the notification area. Click its eye icon to reopen it, or choose Quit EyeCopy to stop it. With background use disabled, closing the window quits. A newly connected device can open the window while EyeCopy is running; EyeCopy does not register a Windows startup task.

Check for updates

Open Settings to check for a newer release and choose automatic update checks. UpdateEyeCopy.exe in the application folder opens the same controls. Checks use the publisher's public GitHub release repository. If the package does not supply one, enter the repository URL in Settings. Automatic checks are enabled by default when a repository is configured and can be turned off. With no repository configured, EyeCopy makes no update requests.

The updater downloads the versioned Windows setup asset from a stable release and verifies it against that release's SHA256SUMS.txt. Installation requires confirmation. Updates preserve settings, catalogues, cached previews and downloaded originals.

For a manual update, quit EyeCopy from its notification-area menu and run the new setup. For portable use, you can instead extract the complete updated package into a new folder. Settings and previews are stored separately from the application, normally in %LOCALAPPDATA%\EyeCopy.

Uninstall and clear application data

Quit EyeCopy, then use its entry in Windows Settings → Apps → Installed apps, or open UninstallEyeCopy.exe in its application folder. Review the application and profile locations shown, then confirm removal.

The uninstaller removes verified application files and clears known data in verified EyeCopy profiles, including its default %LOCALAPPDATA%\EyeCopy location and registered dedicated custom profiles. This clears settings, saved devices, catalogues, history, download tracking, preview caches and logs. A reinstall starts with a fresh catalogue.

Downloaded photos and videos remain in their saved folders. Their previous On PC tracking is cleared with the profile; the files remain usable in File Explorer. Device originals, shared Apple USB support and other applications' profiles stay in place. The cleanup verifies ownership and folder safety. Unrelated files, modified application files, locked items and unverified locations are retained and reported for manual review; their containing folders may remain.

Deleting the application folder by hand leaves its separate profile in place. Use the included uninstaller when you want that application data cleared too.
