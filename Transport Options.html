USB connection details

EyeCopy includes its application dependencies. Device access also depends on Windows USB support, the cable and port, and the permissions granted by iOS or iPadOS.

Desktop interface and transfer engineIncluded in the portable package. No Node.js or Python installation.

First-time setup

Install Apple Devices from the Microsoft Store if compatible Apple USB support is missing. Open it once, connect an unlocked device and approve Trust. Apple provides download guidance and a USB connection checklist.

After setup, the Apple Devices window may stay closed while EyeCopy transfers files. Its background transport must remain available. Existing compatible Apple support can be reused. EyeCopy does not replace the installed driver binding or install a separate device service.

USB link and file-copy speed

A USB 3 link requires a supporting device, data cable and PC port. Some devices and cables support only USB 2. The negotiated link shown in the device panel is a connection ceiling, rather than measured file throughput.

The transfer queue reports actual MB/s. Device file services, protocol overhead, storage speed, preview playback and other activity can reduce throughput. Installing Apple Devices alone does not guarantee USB 3, 10 Gbps or a specific copy speed. Avoid equating a cable's or port's advertised rate with the speed of an original-file transfer.

Accessible device folders

Photos App reads camera originals. Files App uses participating apps' shared Documents directories. It does not provide unrestricted access to Files, iCloud Drive, Safari Downloads or private storage. A separately signed device companion can expose its own Documents directory, but does not remove the Windows USB or device-permission requirements.

The desktop USB route cannot delete items from the Photos library or send device files to Recently Deleted. Deletion inside supported shared-app folders is permanent and requires confirmation. Existing PC copies are not removed by device deletion.

Use without a connected device

Saved catalogues and cached previews remain available offline. Downloaded originals play from local storage. Obtaining new device files or previews, uploading, and streaming from the device require a connection.
